v1.0.3Pre-release 测试版2026-11-20

基于 Zalith Launcher 1 原版底层重新开发，界面引擎 Jetpack Compose，视觉风格拟物沉浸风。

修复
  • 修复用户须知协议门禁：此前协议界面定义了却从未在主界面启动时调用，未同意即可进入主界面；现已强制首次启动弹出，未同意不得使用下载、联机、AI 等功能
  • 修复同意回调中的递归错乱，同意后正常关闭遮罩并继续初始化，拒绝则退出
  • 修复用户须知中文缺失：新增简体/繁体协议本地化资源，中英文均可滚动阅读
新增功能
  • AI 助手「分析启动日志」专项：自动导入最近日志、脱敏（令牌/API Key/UUID/路径用户名）、摘要提取错误行，上传前弹窗告知并取得确认
  • AI 助手入口：主界面右上角功能区从右往左第 5 个位置，长按显示功能名称
  • 设置页新增 AI 助手分组与「重新查看用户须知」入口
界面
  • 主界面、设置、下载、用户须知、陶瓦联机、AI 助手统一拟物沉浸风设计 token
  • 陶瓦联机：用户须知 / 房主教程 / 房客教程三标签，未读须知时锁定首标签
  • 恢复 ZL1 原版布局与入口顺序，仅迁移 UI 引擎
签名
  • 本次构建使用全新独立签名证书 Cubern Launcher（SHA-256: 206009225b0a64d95228811adfc6b0635ae8bd16e136d901b92e9994e0240fcb）
  • 注意：更换签名后，已安装旧版的用户升级时必须先卸载旧版
构建
  • Gradle 8.11.1 / JDK 17 / Android SDK 34 / NDK 25.2.9519653，BUILD SUCCESSFUL（59 tasks）
v1.0.2Pre-release 测试版2026-11-17
主界面还原 Zalith Launcher 1 布局
  • 恢复原版双栏结构：左侧菜单栏（6.5 份）+ 右侧启动面板（3 份）
  • 顶栏右侧四个图标：打开主目录、陶瓦联机、下载、设置
  • 右侧面板最左侧新增启动器动画（呼吸缩放 + 旋转 + 渐变光晕）
  • 左侧菜单保留版本管理、模组管理、文件管理、执行 JAR；UI 底层替换为 MIUIX Compose
设置页导航重排
  • 导航顺序：视频 → 游戏 → 启动器 → 实验性 → 控制布局 → 关于本启动器
  • 控制布局位于倒数第二，关于本启动器位于最后；关于页保留介绍、开发者致谢与检查更新
陶瓦联机独立化
  • 从设置中移除，成为独立功能；顶栏按钮与游戏内启动器菜单均可进入
  • 新增 TerracottaActivity 独立承载联机界面
  • 引入 Zalith Launcher 2 的完整陶瓦联机实现（Terracotta + EasyTier）
用户须知协议
  • 首次启动时在安装运行时组件之前展示，需明确同意后才能继续
  • 声明基于 Zalith Launcher 1 二改、非官方声明、网络与账号、本地存储、GPL v3.0、免责声明
AI 版本助手（第五个功能）
  • 离线版本体检、运行时完整性校验与缺失文件提示、版本管理建议
  • 设计参考 Amethyst-iOS 与 MyRemasteredAI，支持自备 USER_LLM_API_KEY
其他优化
  • 运行时按需安装：按版本号语义比较判断所需 Java 主版本，仅准备对应运行时
  • 下载动画重写：TextProgressBar 改为平滑追赶动画，进度不回退
  • 安装包按 ABI 拆分全部低于 200 MB（arm64 159MB / v7a 153MB / x86 144MB / x86_64 162MB）
v1.0.1Pre-release 测试版2026-11-16
陶瓦联机完整移植
  • 从 Zalith Launcher 2 移植陶瓦联机（Terracotta）模块完整实现
  • 原生桥接层 TerracottaAndroidAPI 与 libterracotta.so（四 ABI）
  • VPN 隧道服务 TerracottaVPNService 与独立前台通知渠道
  • EasyTier 节点拉取，支持自定义节点；房主/房客双模式、房间码生成与校验、完整状态机
  • 联机日志采集与异常原因提示，中英文文案资源
MIUIX 主界面彻底重构
  • MIUIX Compose 界面完全替代原 View 布局，旧的 LauncherActivity 与 MainMenuFragment 已删除
  • 右上角新增「打开主目录」与「陶瓦联机」入口
  • 主界面布局与原版一致：当前版本卡片、启动游戏、版本选择、执行 JAR、设置入口
  • 关于启动器与控制布局整合进设置界面
其他修复
  • 关于启动器文案更新为「基于 Zalith Launcher1 进行二改开发」，中英文同步
  • 更新下载进度动画重写为平滑追赶式进度条，进度不会回退
  • 下载平台修复：未配置 CurseForge API Key 时自动隐藏并回退到 Modrinth
  • 下载源镜像路径映射验证与修复
v1.0.0首个测试版2026-11-16
本版本内容
  • 26.2+ 运行环境支持：版本号语义比较，杜绝伪造或跳过版本号绕过限制
  • Java 运行时自动管理：自动识别、下载、校验并注入兼容运行时
  • 陶瓦联机功能：入口位于主界面右上角
  • Vulkan 支持检测：核验 API、物理设备、1.2 能力、图形队列、表面扩展与原生库
  • 四种渲染模式：跟随游戏、OpenGL、Vulkan、自动选择

  • MIUIX Compose UI：主界面与设置界面采用 MIUIX 框架重写布局
  • 设置界面整合：原主界面的「关于启动器」与「管理控制」布局已合并进设置
底层优化
  • 依赖库去重：按 groupId:artifactId:version:classifier:abi 去重
  • 安全回退：环境不满足时给出明确原因并回退到兼容渲染后端
  • 兼容性：保留 26.2 之前正式版、快照、Forge / Fabric / NeoForge / Quilt 等自定义环境的启动能力
