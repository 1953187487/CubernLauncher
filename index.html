Features

为手机端而生的启动体验

从联机到渲染，从界面到运行时，每一项都是为了让 Minecraft Java 版在 Android 上跑得更顺、更自由。

🌐

陶瓦联机完整移植

移植 Zalith Launcher 2 的 Terracotta + EasyTier 实现，房主/房客双模式、房间码校验、VPN 隧道与节点自选，手机也能和朋友联机。

Terracotta · EasyTier

Build

开源、透明、可自行构建

基于 Zalith Launcher 1 二次开发，遵循 GNU GPL v3.0，代码公开可审计。

# local.properties sdk.dir=/path/to/android-sdk # 构建 Release ./gradlew :CubernLauncher:assembleRelease # 按 ABI 打包 ./gradlew :CubernLauncher:assembleRelease -Darch=arm64

构建环境

  • Android SDK 34
