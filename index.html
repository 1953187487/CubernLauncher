Features

为手机端而生的启动体验

从联机到渲染，从界面到运行时，每一项都为了让 Java 版在 Android 上跑得更顺、更自由。

陶瓦联机完整移植

移植 Zalith Launcher 2 的 Terracotta + EasyTier 实现，房主/房客双模式、房间码校验、VPN 隧道与节点自选。

Terracotta · EasyTier

MIUIX Compose 界面

还原经典双栏布局，呼吸缩放、旋转、渐变光晕的启动动画。

MIUIX

AI 版本助手

离线版本体检与运行时匹配校验，支持自备 API Key 问答。

离线体检

Java 运行时管理

语义比较版本、按需注入兼容运行时、架构与完整性校验。

按需安装

Vulkan 渲染

四种渲染模式，能力检测与安全回退，不满足时回退兼容后端。

Vulkan 1.2

自定义环境兼容

支持 Forge / Fabric / NeoForge / Quilt，保留 26.2 之前正式版与快照的启动能力，版本、模组、文件管理一站搞定。

Forge · Fabric · Quilt

Build

开源、透明、可自行构建

基于 Zalith Launcher 1 二次开发，遵循 GNU GPL v3.0，代码公开可审计。

# local.properties sdk.dir=/path/to/android-sdk # 构建 Release ./gradlew :CubernLauncher:assembleRelease # 按 ABI 打包 ./gradlew :CubernLauncher:assembleRelease -Darch=arm64
