更新公告

版本更新与已知说明，第一时间掌握。

v1.0.3Pre-release 测试版2026-11-20

基于 Zalith Launcher 1 原版底层重新开发，界面引擎 Jetpack Compose，视觉风格拟物沉浸风。

修复
  • 修复用户须知协议门禁：此前协议界面定义了却从未在主界面启动时调用，未同意即可进入；现强制首次启动弹出，未同意不得使用下载、联机、AI 等功能
  • 修复同意回调中的递归错乱，同意后正常关闭遮罩并继续初始化，拒绝则退出
  • 修复用户须知中文缺失：新增简体/繁体协议本地化资源，中英文均可滚动阅读
新增功能
  • AI 助手「分析启动日志」专项：自动导入最近日志、脱敏（令牌/API Key/UUID/路径用户名）、摘要提取错误行，上传前弹窗告知并取得确认
  • AI 助手入口：主界面右上角功能区从右往左第 5 个位置，长按显示功能名称
  • 设置页新增 AI 助手分组与「重新查看用户须知」入口
界面
  • 主界面、设置、下载、用户须知、陶瓦联机、AI 助手统一拟物沉浸风设计 token
  • 陶瓦联机：用户须知 / 房主教程 / 房客教程三标签，未读须知时锁定首标签
  • 恢复 ZL1 原版布局与入口顺序，仅迁移 UI 引擎
签名变更提示：本次构建使用全新独立签名证书 Cubern Launcher（SHA-256: 206009225b0a64d95228811adfc6b0635ae8bd16e136d901b92e9994e0240fcb）。更换签名后，已安装旧版的用户升级时必须先卸载旧版。

Features

为手机端而生的启动体验

从联机到渲染，从界面到运行时，每一项都为了让 Java 版在 Android 上跑得更顺、更自由。

陶瓦联机完整移植

移植 Terracotta + EasyTier 实现，房主/房客双模式、房间码校验、VPN 隧道与节点自选，手机也能和朋友联机。

Terracotta · EasyTier

MIUIX Compose 界面

还原经典双栏布局，呼吸缩放、旋转、渐变光晕的启动动画。

MIUIX

AI 版本助手

离线版本体检与运行时匹配校验，支持自备 API Key 问答。

离线体检

Java 运行时管理

语义比较版本、按需注入兼容运行时、架构与完整性校验。

按需安装

Vulkan 渲染

四种渲染模式，能力检测与安全回退。

Vulkan 1.2

自定义环境兼容

支持 Forge / Fabric / NeoForge / Quilt，保留 26.2 之前正式版与快照的启动能力。

Forge · Fabric · Quilt
