# Cubern Launcher 隐私协议

**版本：v1.0 · 生效日期：2026-11-27**

Cubern Launcher 重视您的隐私。本协议说明我们如何处理您的数据。

## 一、我们收集的数据
**我们不使用任何自动埋点或遥测服务。** 启动器仅在本地处理您的游戏版本、账号凭据（加密）、设置项、皮肤与日志。

## 二、网络请求
启动器会向 Microsoft 认证、BMCLAPI/Mojang 资源源、Modrinth/CurseForge、GitHub（更新与公告）、以及您配置的 AI/第三方登录服务器发起请求。

## 三、AI 助手
AI 助手需您自备 API Key，我们不会收集。日志分析前会脱敏（令牌/Key/UUID/路径）。

## 四、陶瓦联机
使用 EasyTier P2P，游戏流量设备间直连，启动器不记录对局内容。

## 五、崩溃日志
如您主动反馈，日志在**您确认后**上传且经过脱敏。

## 六、您的权利
您可随时清除数据、删除账号、卸载应用。我们不保留任何可识别您身份的服务器端数据。
