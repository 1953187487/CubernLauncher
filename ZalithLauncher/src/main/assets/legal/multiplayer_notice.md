# Cubern Launcher 联机功能用户须知

**版本：v1.1 · 生效日期：2026-11-27**

## 一、联机功能说明
Cubern Launcher 提供两种联机方式：

### 1. 陶瓦联机
基于开源 EasyTier P2P 协议的 Minecraft Java 版联机方案，通过房间码创建或加入房间，游戏流量在设备间直接传输，不经过本项目服务器。使用需授予 VPN 权限。

### 2. 爱发电联机（Cubern 独有）
基于爱发电社交关系的联机系统。**只要用户之间私聊过、或互相关注过，就可以直接联机。** 使用前需登录爱发电账号。

## 二、爱发电联机联机条件
满足以下任一条件即可互相联机：
1. 私聊过 —— 双方曾在爱发电上进行过私聊；
2. 互相关注 —— 双方互相关注了对方的爱发电账号。

## 三、联机流程
1. 房主在联机功能中选择"爱发电联机"，从符合条件的好友列表选择邀请对象。
2. 受邀玩家若也安装 Cubern Launcher，将在启动器左侧收到类似游戏邀请的通知。
3. 点击同意后，启动器自动下载房主端对应的模组与配置参数，并自动启动游戏加入房间。
4. 若房主停止房间，受邀端会自动向房主发送重开请求。

## 四、隐私与数据
- 爱发电凭据仅本机加密保存，不上传服务器；用于判断私聊/互相关注关系与发送邀请。
- 陶瓦联机房间码与 VPN 配置仅在本机与对端之间交换。
- 好友关系与邀请信息仅用于联机功能。
