# Cubern Launcher 联机功能用户须知

**版本：v1.0 · 生效日期：2026-11-27**

## 一、联机功能说明

Cubern Launcher 提供两种联机方式：

### 1. 陶瓦联机
基于开源 EasyTier P2P 协议的 Minecraft Java 版联机方案。通过房间码创建或加入房间，游戏流量在设备间直接传输，不经过本项目服务器。使用此功能需要授予 VPN 权限。

### 2. 爱发电联机（Cubern 独有）
基于爱发电平台的社交关系构建的联机系统。**只要用户之间私聊过、或互相关注过，就可以直接联机。**

## 二、爱发电联机的联机条件

满足以下任一条件的用户，即可互相联机：

1. **私聊过** —— 双方曾在爱发电上进行过私聊；
2. **互相关注** —— 双方互相关注了对方的爱发电账号。

使用前需登录爱发电账号，启动器将根据上述条件同步可联机的好友列表。

## 三、联机流程

1. 房主在联机功能中选择"爱发电联机"，从符合条件的好友列表中选择要邀请的玩家。
2. 受邀玩家若也安装了 Cubern Launcher，将在启动器左侧收到类似游戏邀请的通知。
3. 受邀玩家点击同意后，启动器自动下载房主端对应的模组与配置参数，并自动启动游戏加入房间。
4. 若房主停止房间，受邀端会自动向房主发送重开请求。

## 四、隐私与数据说明

- 爱发电联机需要您提供爱发电登录凭据，用于判断私聊/互相关注关系并发送邀请。
- 我们**不会存储您的爱发电密码**，凭据仅在本机加密保存。
- 好友关系、邀请信息仅用于联机功能，不会上传至我们的服务器（除必要的邀请中转外）。
- 陶瓦联机的房间码与 VPN 配置仅在本机与对端之间交换。
