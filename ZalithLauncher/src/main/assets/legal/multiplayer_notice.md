# Cubern Launcher 联机功能用户须知

**版本：v2.0 · 生效日期：2026-11-28**

## 一、联机功能说明
Cubern Launcher 提供基于开源 EasyTier P2P 协议的 Minecraft Java 版联机方案 —— 陶瓦联机，并支持游戏内服务器入口。

## 二、陶瓦联机
- 通过房间码创建或加入房间，游戏流量在设备间直接传输，不经过本项目服务器。
- 使用此功能需要授予 VPN 权限，请确认您了解该权限的含义。
- 房间码与 VPN 配置仅在本机与对端之间交换。

## 三、联机流程
1. 房主开启联机并创建房间，获取房间码并发送给好友。
2. 受邀玩家输入房间码加入房间。
3. 若房主停止房间，受邀端会收到提示。

## 四、隐私与数据
房间码、好友关系与联机配置仅用于联机功能，不会上传至我们的服务器。
