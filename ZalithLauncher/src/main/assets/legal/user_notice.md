# Cubern Launcher 用户须知

**版本：v2.1 · 生效日期：2026-11-28**

欢迎使用 Cubern Launcher。使用前请完整阅读本须知。

## 一、项目来源
Cubern Launcher 由鹙鸟独立维护，基于 Zalith Launcher 2 深度二改，是一款非官方 Minecraft Java 版 Android 启动器。

## 二、非官方声明
本启动器与 Mojang Studios、Microsoft、网易公司无任何隶属、授权或合作关系。Minecraft 是 Mojang Studios 的商标。本项目不分发任何游戏本体内容，请自备正版账号与游戏文件。

## 三、账号与网络
- 启动器联网用于获取版本清单、依赖库、资源文件与 Java 运行时。
- 正版登录时账号凭据仅发送至 Microsoft 官方认证服务器或您自行配置的第三方认证服务器。
- 下载模组、光影、游戏版本时，请求会发送至 Modrinth、CurseForge、BMCLAPI 等公开资源源。

## 四、本地存储
游戏版本、依赖、资源包、存档、账号、设置、皮肤、日志均保存在您的设备。您可随时清除数据。

## 五、联机功能
陶瓦联机基于 EasyTier P2P，需授予 VPN 权限，房间码与联机配置仅在设备间交换。

## 六、Rust 版 Minecraft
启动器提供 Horizon Android 入口。Horizon 从 Mojang 官方源下载 Minecraft Java 26.3 游戏资源（约 500MB），本项目不分发游戏文件。多人服务器需正版账号。

## 七、Cubernai 键位 AI
在本地为您提供键位布局建议，不上传您的操作数据。
