# Cubern Launcher 用户须知

**版本：v1.0 · 生效日期：2026-11-27**

欢迎使用 Cubern Launcher。在开始前，请完整阅读以下内容。

## 一、项目来源
Cubern Launcher 是一款基于 **Zalith Launcher 2** 二次开发的非官方 Minecraft Java 版 Android 启动器，由 **鹙鸟** 独立维护。

## 二、非官方声明
本启动器**不是官方产品**，与 Mojang Studios、Microsoft、网易公司没有任何隶属、授权或合作关系。Minecraft 是 Mojang Studios 的商标，本项目不分发任何游戏本体内容。

## 三、账号与网络
- 启动器需要联网获取游戏版本清单、资源文件、依赖库与 Java 运行时。
- 正版登录时，账号凭据发送至 Microsoft 官方认证服务器。
- 除认证必需信息外，启动器不会上传您的个人文件。
- AI 助手需自备 API Key，日志分析前会脱敏处理。

## 四、本地存储
游戏文件、账号、设置、皮肤、日志均保存在您的设备。您可随时清除应用数据。
